## Project Overview

Syntax Atlas is a Thai-first syntax reference and comparison app for developers. It lets users search programming topics, browse supported languages, and compare syntax examples across Python, JavaScript, TypeScript, Go, Rust, and Java.

## Tech Stack

| Layer | Technology | Notes |
|-------|-----------|-------|
| Framework | Next.js 16 App Router | Server components by default; client components only where browser state/APIs are needed |
| Language | TypeScript | Strict mode enabled; `@/*` path alias maps to `src/*` |
| UI | React 19 | Component-based pages under `src/app` |
| Styling | Tailwind CSS 4 | Global theme variables in `src/app/globals.css` |
| Search | Fuse.js | Client-side fuzzy topic search in `SearchBox` |
| Code Highlighting | Shiki | Server-rendered highlighted code HTML in `CodeBlock` |
| Content | Local JSON files | Languages, topics, and examples live under `src/content` |
| Fonts | `next/font/google` | Geist, Geist Mono, and Noto Sans Thai |

## Project Structure

```text
src/
├── app/                  # Next App Router routes and global layout/styles
│   ├── compare/          # Syntax comparison page
│   ├── languages/        # Language listing and language detail routes
│   ├── topics/           # Topic listing and topic detail routes
│   └── web/              # Web frameworks-per-language section (separate lib)
├── components/           # Reusable UI components
├── content/              # JSON-backed language, topic, and example data
│   ├── examples/         # Per-language syntax examples
│   └── web/              # Per-language web library/framework data (separate)
└── lib/                  # Content access helpers and shared types
```

The **Web** section is intentionally a **separate content lib**: `src/lib/web.ts`
+ `src/content/web/**` are independent of the topic/example atlas in
`content.ts`. It only reuses the `languages` registry for display.

## External Dependencies & APIs

The app currently has no external API, database, or auth dependency. Runtime content comes from local JSON files. Google fonts are loaded through `next/font/google` during build/runtime as configured by Next.js.
