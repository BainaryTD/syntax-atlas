# Syntax Atlas

แผนที่ syntax สำหรับนักพัฒนาไทย — ค้นหาและเปรียบเทียบ syntax ของหลายภาษา programming ในที่เดียว

## MVP

- ภาษา: Python, JavaScript, TypeScript, Go, Rust, Java
- หัวข้อ: Hello World, Comment, Variable, If Else, For Loop, While Loop, Function, Array/List, Object/Map/Dict, Error Handling
- Stack: Next.js + TypeScript + Tailwind CSS
- Content: JSON
- Syntax Highlight: Shiki
- Search: Fuse.js

## Development

```bash
npm install
npm run dev
```

เปิดเว็บที่ `http://localhost:3000`
